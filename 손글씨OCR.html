    Gemini API 설정

    처음이라면 아래 순서대로 무료 API 키를 받아 붙여 넣고 연결 테스트를 눌러 보세요. 5분이면 됩니다.

    1. Google AI Studio 접속 — aistudio.google.com 에 들어가 평소 쓰는 Google 계정으로 로그인합니다. 처음이면 이용약관 동의 창이 뜹니다.
    2. API 키 메뉴로 이동 — 왼쪽 메뉴의 Get API key(API 키 가져오기)를 누르거나 바로 aistudio.google.com/apikey 로 갑니다.
    3. 키 만들기 — Create API key(API 키 만들기)를 누릅니다. 프로젝트를 고르라고 하면 기본 프로젝트를 고르거나 새로 만들면 됩니다.
    4. 키 복사 — 만들어진 키 옆 복사 버튼을 누릅니다. 요즘 발급되는 키는 AQ. 으로 시작합니다. (예전 키는 AIza 로 시작하며, 둘 다 사용할 수 있습니다.)
    5. 붙여 넣고 테스트 — 아래 칸에 붙여 넣고 연결 테스트 → 성공하면 저장을 누릅니다.

    • 무료 등급은 분당·하루 사용량 한도가 있어 한꺼번에 많은 쪽을 판독하면 잠시 기다리라는 메시지가 나올 수 있습니다. 사용량은 AI Studio 사용량에서 볼 수 있습니다.
    • 키는 비밀번호처럼 다루세요. 이 브라우저에만 저장되며 Google API 호출에만 쓰입니다. 공용 PC라면 사용 후 키를 지우세요.
